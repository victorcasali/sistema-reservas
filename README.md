# Sistema de Reservas de Restaurante

Projeto desenvolvido em Python para praticar Programação Orientada a Objetos (POO).

A ideia é desenvolver um sistema para auxiliar no gerenciamento de um restaurante, permitindo cadastrar mesas e clientes, criar reservas e controlar a disponibilidade dos horários.

O projeto está sendo desenvolvido por etapas, começando pela estrutura das classes e regras de negócio, com planos de implementar futuramente um menu interativo e armazenamento em banco de dados.

## Funcionalidades implementadas

- Cadastro e representação de clientes.
- Cadastro e representação de mesas.
- Verificação da capacidade das mesas.
- Criação de reservas.
- Numeração automática das reservas.
- Verificação de conflitos entre reservas, considerando mesa, data e horário.

## Tecnologias utilizadas

- Python 3
- Programação Orientada a Objetos (POO)
- Git e GitHub

## Estrutura do projeto

- `main.py` – Arquivo principal do sistema.
- `cliente.py` – Classe responsável pelos clientes.
- `mesa.py` – Classe responsável pelas mesas e sua capacidade.
- `reserva.py` – Classe responsável pelas reservas.
- `restaurante.py` – Classe que gerencia os cadastros e as regras de reserva.

## Próximas implementações

- Validação completa das reservas.
- Listagem, busca, edição e cancelamento de reservas.
- Menu interativo para utilização do sistema.
- Integração com banco de dados SQLite.
